# Components

## Structure
- **Base Components**: `src/components/`
- **Feature Sections**: `src/sections/`
- **Layouts**: `src/layouts/`

## UI Components
`src/components/` - Reusable UI elements
- `animate/` - Animation components
- `custom-avatar/`, `custom-input/`, `custom-tabs/`
- `table/`, `upload/`, `modal-*/`
- `settings/` - Settings UI

## Feature Components  
`src/sections/` - Feature-specific components
- `auth/` - Authentication forms
- `dashboard/` - Dashboard views
- `code-panel/` - Code editor interface
- `student-profile/`, `challenges/`

## Layouts
`src/layouts/`
- `dashboard/DashboardLayout.tsx`
- `login/LoginLayout.tsx`  
- `compact/CompactLayout.tsx`

## Styling
Material-UI + custom theme
- `src/theme/` - Theme configuration
- Component overrides in `src/theme/overrides/`
