# Styling

## Theme System
Material-UI with custom theme configuration

## Theme Files
- `src/theme/index.tsx` - Main theme provider
- `src/theme/palette.ts` - Color definitions
- `src/theme/typography.ts` - Font settings
- `src/theme/customShadows.ts` - Shadow definitions

## Component Overrides
`src/theme/overrides/` - Material-UI component customizations
- Button, TextField, Card, Dialog, etc.

## Global Styles
- `src/theme/globalStyles.tsx` - Global CSS
- `public/fonts/index.css` - Font imports
- Custom fonts: CircularStd, Roboto, Rajdhani

## Settings
- `src/components/settings/` - Theme switching (light/dark mode)
- Dynamic theme configuration via settings context
